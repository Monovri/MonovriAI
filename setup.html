👋 Kurzes Setup

Damit deine Inhalte zu deinem Business passen, brauchen wir ein paar Angaben — dauert 2 Minuten.

Diese Angaben nutzen wir nur, um deine Inhalte/Antworten passend zu formulieren.
Ersetzt die Standardfarbe im Chat-Button/-Header auf deiner Website.
Findest du in Cal.com unter Settings → Developer → API Keys. Ohne API-Key wird der Termin stattdessen per E-Mail an dich zur manuellen Eintragung geschickt.
Findest du in der URL deines Event-Types in Cal.com unter Event Types → dein Termin-Typ → Einstellungen.
